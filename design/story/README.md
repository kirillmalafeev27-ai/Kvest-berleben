# STORY — играбельный сценарий (референсная линия «Соискатель»)

Здесь дизайн-библия (`../`) превращается в **конкретный играбельный контент**: сюжет,
персонажи с живыми диалогами, прописанные встречи-сцены с ветками «что куда ведёт», и пул
событий в готовой YAML-схеме.

## Почему одна линия вглубь, а не семь вширь

Полностью прописать диалоги/сцены/ветки для всех 7 магистральных линий (`../02`) — это объём
романа. Куда полезнее для реализации **довести до играбельности одну линию целиком**, на которой
обкатывается весь движок (Parser→Rules→Narrator→Analyst, граф слухов, события). Выбрана
**«Соискатель»** — постсоветский айтишник, Jobseeker-виза §20, 90 дней (это и есть герой v0.1,
и MVP-рекомендация из `../02`).

Все механизмы (формат сцены, схема события, голос-карточки, карта «что куда ведёт») —
**переиспользуемые**: остальные 6 линий собираются теми же лекалами с другим реквизитом и
другой общиной. Где линия даёт уникальную перекраску — помечено `↪ перекраска:`.

## Формат сцены (единый для актов 02–04)

```
### СЦЕНА s_id — «Название»  (день D, локация loc, узел Nx если есть)
Вход: предикаты (день/флаги/оси/навыки/репутация).
Факты сцены (для Narrator; вне списка выдумывать нельзя):
  - ...
Завязка: 1–2 фразы обстановки.

[Имя NPC]: «реплика на его голосе»

▷ ИГРОК → <интент> (verb/method/honesty/tone):
    Исход: что происходит (резолв).
    Δ: дельты-подсказки осей · 🏷 слухи/заметки · 🎲 скилл-чек если есть
    ⇒ ВЕДЁТ К: s_следующая / флаг / арка / концовка
(повторить для каждой осмысленной ветки)

Выходы из сцены: куда мир двигается дальше.
```

Этот формат одновременно **читается как сценарий** и **ложится в схему событий** `../05`
(`scene_facts`, `branches[].match_intents`, `delta_hints`, `rumor_tags`, `followups`).

## Условные обозначения

- **Δ** — подсказки дельт осям для Analyst (он скорректирует по контексту, код клампит).
- **🏷** — слух (тег+фракция) или заметка в дело чиновников.
- **🎲** — скилл-чек (навык vs порог).
- **⇒ ВЕДЁТ К** — куда ветка перебрасывает игрока (другая сцена / флаг / арка / концовка). Это и есть «что куда ведёт».
- **Nx** — узел-«стрелка» из `../04` (N1…N9).
- **↪ перекраска** — как сцена переигрывается для другой магистральной линии.
