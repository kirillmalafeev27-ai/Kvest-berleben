# SCENARIO3D — производственный сценарий игры (одна линия, до конца)

Ответ на вопрос «а какая, собственно, у игры сюжетная линия?». Здесь дизайн-библия (`../`)
и текстовый сюжет (`../story/`) сведены в **один конкретный производственный пакет**:
линия «Соискатель» в 3D — какие сцены, какие персонажи и локации из каталога, какие развилки,
какие объекты и какие Mixamo-анимации в каждом бите.

**Три опоры пакета:**
1. **Каталог Meshy (`../13`) — единственный источник ассетов.** Все сцены собраны из
   H01–H16 + E01–E34 + примитивов/декалей. Ни одного «нужно докупить».
2. **Текстовый канон (`../story/`) не переписывается** — скрипт ссылается на него
   (сцены, Δ, 🏷, флаги, концовки), добавляя постановку, анимации и языковой слой.
3. **Немецкий — это геймплей.** Игра качает язык на любом уровне (A0–C1), не останавливая
   сюжет: уровень героя = уровень игрока.

## Как это стыкуется с остальным репозиторием

- Сцены скрипта = сцены событийной схемы `../05` и YAML-контента `../../prototype/content/`
  (те же id: `s_buergeramt`, `s_zoll_raid`…). 3D-слой — поверх, не вместо.
- Словарь `A##` — это словарь `anim` контракта `scene_actions` (`../12`): и скриптовые сцены,
  и эмерджентные действия («бью прохожего») играются из одного набора клипов.
- Риг и пайплайн персонажей — `../13` §6 (один скелет, Mixamo-совместимо, эталон H13).
- Локации-сборки соответствуют реестру id `../06` §6.4.
