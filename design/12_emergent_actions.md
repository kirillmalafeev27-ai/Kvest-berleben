# 12. ЭМЕРДЖЕНТНЫЕ ДЕЙСТВИЯ: «текст → живая сцена без скрипта»

> Задача: игрок пишет любое действие («бью прохожего»), и оно **разыгрывается в 3D** —
> анимация, реплика, ответный удар, падение — без заранее написанного скрипта на этот случай.
> Здесь: **все реальные варианты** это сделать (матрица) и пометка, что из них **реализовано в
> репозитории** (`prototype/web/`), что — адаптер/скаффолд, а что — фронтир.

## Ключевая правда

Сервиса, который из текста **рисует новую анимацию покадрово** в реальном времени, в продакшене
нет (это research, text-to-motion — ненадёжно). Рабочий приём везде один:
**LLM-«мозг» → структурный план действий (`scene_actions`) → движок проигрывает из набора
анимаций + физика + живая озвучка.** «Скрипта нет» — потому что планов бесконечно много и реплики
генерятся на лету. Это тот же принцип, что во всём нашем дизайне: закрытый словарь (теперь —
анимаций/абилок) + LLM-оркестратор.

Универсальный интерфейс, к которому подключаются ВСЕ варианты, — контракт `scene_actions`:
```json
[
  {"actor":"player","anim":"punch","target":"passerby_01"},
  {"actor":"passerby_01","anim":"hit_react","say":"ты чего?!"},
  {"actor":"passerby_01","anim":"punch","target":"player"},
  {"actor":"player","anim":"fall","ragdoll":true}
]
```

## Что собрано в репозитории (рабочее, прямо сейчас)

**`prototype/web/` — браузерная демка, вариант `1B+2B+3A+4A/4D`:**
- открываешь `index.html` → low-poly улица, герой + прохожие (процедурные human-boxes, **без ассетов**);
- пишешь в строку «бью прохожего» / «обними его» / «дай денег» / «убегаю» / «танцую» / «угрожаю» …;
- офлайн-режиссёр (`director.js`) превращает текст в `scene_actions`, сцена их проигрывает: удар, recoil, **ответный удар, падение**, реплики голосом + пузырём;
- **никакого скрипта на конкретный случай** — план генерится каждый раз из словаря анимаций.

**Точки подключения «по-взрослому» (хуки уже есть):**
- `director.js` → `BRAIN = 'offline' | 'claude' | 'inworld' | 'convai'` (свой LLM по нашему контракту, или сторонний мозг);
- озвучка → `VOICE = 'browser' | 'elevenlabs'`;
- движение → можно заменить процедурные позы на Mixamo-клипы (раздел «как» в `web/README.md`).

**`prototype/berlin/scene.py`** — тот же генератор `scene_actions` на стороне движка (для серверного
пути Python/Claude); включён в ответ Ведущего (`gm.py`), так что и текстовый прототип, и веб-сцена
говорят на одном контракте.

## Как выбрать вариант под себя (рекомендация)

- **Прототип/демо, браузер, 0 бюджета** → `1B/1A + 2B + 3A + 4A` — это и собрано здесь. Включаешь Claude (`1A`) ключом — мозг становится «живым».
- **Качество NPC без своей возни с диалогами** → `1C/1D Inworld/Convai + 3B Unity/Unreal`.
- **Кинематографичные говорящие лица** → добавить `4B ElevenLabs + 4C Audio2Face`.
- **Уникальные движения** → офлайн готовишь клипы через `2C DeepMotion/Move AI`, в рантайме их сцепляет LLM (`2A`).

Контракт `scene_actions` одинаков во всех ветках — мозг и рендер можно менять независимо.

Реализация и инструкции по подключению — `prototype/web/` и `prototype/web/README.md`.
