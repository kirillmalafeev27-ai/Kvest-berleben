# 09. ПЕРСОНАЖИ (NPC)

Реестр NPC поверх 10 из v0.1 (§3.3), расширенный под общины и магистральные линии (`02`).
Каждый NPC — это **стиль-карточка** (для Narrator), **оси-ориентир** (как он сам себя ведёт),
**фракция**, **роль в ветках** и **что помнит/как сплетничает** (для графа молвы, v0.1 §2.4).

> Narrator получает стиль-карточку NPC + факты сцены + резолв. Он **не выдумывает** за NPC
> обещаний/цен/предметов вне стейта (v0.1 §4.2). «Голос» NPC — это тон, словечки, отношение.

## 9.1. Шаблон стиль-карточки

```yaml
id: npc_victor
name: "Виктор"
faction: slavic_street            # к какой фракции относится
nationality: "серб"
role: "проводник криминальной/серой ветки; моральный камертон"
axes_self: { AGGRO: +10, TRUTH: -20, ALTRU: +5, LAW: -50, PRIDE: +15 }   # его собственный профиль
voice:                            # для Narrator
  language: [sr, de_broken, ru]
  register: "разговорный, тёплый цинизм, прибаутки, 'браток'"
  tics: ["всё имеет цену", "это Берлин, детка", смешки]
memory_weight: 3                  # личная память о встречах (×3 к фракционной молве)
gossip_style: "приукрашивает, набивает себе цену, но информацию даёт точную"
relationship_drivers:             # что двигает его отношение к игроку
  likes: [respect, loyalty, paying_debts, useful_skills]
  dislikes: [snitching, naivety_that_costs_him, broken_deals]
gates_content: [victor_pulls_you_in, criminal_contact_finds_you, doctor_intro]
```

## 9.3. Расширение по общинам (новые NPC под линии `02`)

### Арабская община (ветка «Беженец»)
- **`npc_abu_yusuf`** — **Абу Юсуф**, старейшина с Зонненаллее, владелец пекарни. Фракция arabic. Роль: патрон общины, накормит и приютит, но ждёт лояльности и «правильного поведения». Оси: A+, P+, L+, T+. Гейтит: community-поддержку, жильё без формальностей через общину. Молва: его слово в общине — закон.
- **`npc_samira`** — **Самира**, полу-легальная «консультантка» по убежищу. Фракция arabic/gray. Роль: учит «правильной истории» для Anhörung (узел TRUTH-дилеммы). Оси: T−, A+ (искренне думает, что помогает), L−слегка. Гейтит: `bamf_anhoerung` (вариант «отрепетированная история»).

### Турецкая община (ветка «Воссоединение»)
- **`npc_husband_family`** — **Семья мужа/принимающая родня** (коллективный NPC-фракция с правом вето). Роль: жильё/еда/статус «бесплатно», но с условиями; союзники и контролёры внутри. Оси семьи: смешанные (есть и P+ контролёр, и A+ союзник — напр. свекровь vs золовка). Гейтит: автономию, выход «в большой Берлин».
- **`npc_zeynep`** — **Зейнеп**, золовка/подруга, мост к самостоятельности. Фракция turkish. Роль: тайный союзник автономии, сама прошла этот путь. Оси: A+, T+, P+. Гейтит: ветки учёбы/работы вне общины.

### Постсоветская/русскоязычная (ветка «Соискатель»)
- **`npc_oleg`** — **Олег**, русскоязычный «решала» из Charlottengrad, всё «порешает» за процент. Фракция slavic. Роль: серый посредник по документам/работе, со-этническая эксплуатация. Оси: T−, A−, L−слегка, P+. Контраст к бескорыстной Лене.
- **`npc_marina`** — **Марина**, давно осевшая, держит русский магазин, по-матерински помогает новичкам. Фракция slavic. Роль: редкая бескорыстная поддержка в разобщённой общине. Оси: A+, T+, L+.

### Украинская сеть (ветка «Война»)
- **`npc_volunteer_chat`** — **Волонтёрский чат/координаторка Оксана**. Фракция ukrainian/volunteers. Роль: сеть взаимопомощи (жильё, бумаги, переводы), очень активная. Оси: A+, T+, AGGRO+ (пробивная). Гейтит: relief-события, быстрые лайфхаки по §24/Jobcenter.
- **`npc_andriy`** — **Андрій**, земляк с травмой, то опора, то обуза. Роль: зеркало темы «остаться/вернуться» и вины выжившего. Оси: переменные (психо-состояние).

### Восточноевропейская стройка (ветка «Заработок»)
- **`npc_brigadir_janusz`** — **Януш**, польский бригадир-посредник. Фракция black_employers/polish. Роль: даёт работу и жильё-барак, держит на долге, кидает на части денег. Оси: T−, A−, L−, P+. Со-этническая эксплуатация в чистом виде (но с проблесками — иногда реально выручает).
- **`npc_priest_polish`** — **Ксёндз при польском костёле**. Фракция polish/volunteers. Роль: костёл как хаб взаимопомощи, контр-баланс Янушу. Оси: A+, T+, L+.

### Африканская община (ветка «Невидимка»)
- **`npc_pastor_emmanuel`** — **Пастор Эммануэль**, пятидесятническая «церковь в магазине». Фракция african_church. Роль: **безусловная** поддержка (контр-Виктор: помощь без долга-обязательства), надежда, сеть. Оси: A+, T+, P+, L+. Гейтит: `church_service`, путь к легализации через поручительство/брак.
- **`npc_kwame`** — **Кваме**, земляк, который «знает, как тут выжить» вчёрную. Фракция african_street. Роль: уличный проводник, реалист, предупреждает о профилировании. Оси: A+ (к своим), L−, Улица высоко.

### Вьетнамская/китайская (ветка «Студент»)
- **`npc_chi_hoa`** — **Тётушка Хоа**, держит бокс/нейл-салон в Dong Xuan. Фракция vietnamese. Роль: даёт смены (часто сверх лимита — риск визе), землячество, кэш. Оси: A+ (к своим), T−слегка, L−слегка (серая экономика), P−. Гейтит: `dong_xuan` заработок.
- **`npc_wei`** — **Вэй**, китаец-однокурсник, отличник под прессом семьи. Роль: зеркало темы «нельзя подвести родителей», конкуренция и солидарность разом. Оси: T+, A нейтр., P+.

## 9.4. Антагонисты/институты как «лица»

- **`npc_controller_a/b`** — контролёры BVG (событие U-Bahn). Безличны, процедурны — не злодеи, а система. (Гард-рейл 8.4 п.5.)
- **`npc_zoll_officer`** — офицер Zoll на облаве. Тоже процедура, не карикатура.
- **`npc_clerk_generic`** — усталые чиновники Bürgeramt/LEA; пишут заметки в общее дело (v0.1 §2.4). Не злы — перегружены.
- **`npc_cop_profiling`** — полицейский на проверке «в опасном месте». Показывается **системно** (усталость, профиль, отвод глаз), не как злодей-расист (гард-рейл 8.4 п.5).

## 9.5. Заметки для реализации

- Каждый NPC — запись с полями шаблона 9.1; `axes_self` — для согласованности его реплик (Narrator не делает Богдана добряком).
- **Память и молва** (v0.1 §2.4): личная память NPC (вес ×3) + фракционная молва (×1), искажение по графу. Чиновники не сплетничают — пишут в общее дело.
- **Зеркала-контрасты**: на каждого «хищника» есть «святой» в той же общине (Януш↔ксёндз, Виктор/Олег↔Марина, Самира↔Абу Юсуф, Кваме↔пастор Эммануэль). Это и реализм, и гард-рейл против карикатур (8.4 п.4).
- Романтические/семейные NPC (Эмилия, семья мужа) — **зеркала профиля**: их отношение строго следует осям/молве игрока, не сценарной «награде».
- MVP: костяк 9.2 (10 NPC) для линии «Соискатель»; расширение 9.3 подключать вместе с соответствующими бэкграундами.
