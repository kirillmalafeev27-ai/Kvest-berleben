# BERLIN: ÜBERLEBEN — дизайн-библия (макет, v0.2)

> Это **макет**, а не реализация. Цель документа — описать игру настолько полно и
> структурно, чтобы LLM-исполнитель (Claude Code / Codex) мог взять его и собрать
> прототип без додумывания «из воздуха». Любое число, имя, порог и формат здесь —
> предложение по умолчанию, которое можно менять, но нельзя игнорировать.

3D-квест о выживании иммигранта в Берлине. Игрок пишет действия свободным текстом,
LLM-парсер превращает их в интенты, движок резолвит, LLM-рассказчик описывает мир,
LLM-аналитик тихо лепит характер игрока из его поступков. Берлин **запоминает**, кем
ты становишься, и открывает/закрывает перед тобой двери — без полоски «карма».

Тема: не «добро против зла», а **прекарность** — жизнь между статусами, разрыв между
тем, кем ты был дома (инженер, врач, учитель), и тем, кем тебя пускает быть система
(мойщик, курьер, нелегал). Реализм берлинской миграции: бюрократия, теневая экономика,
этнические общины, маленькие сделки с совестью.

## Что нового в v0.2 относительно v0.1

- Вместо одного дефолтного героя — **7 магистральных линий** (выбор в начале), завязанных на реальные правовые статусы и общины.
- Оси личности разложены в **попарные квадранты** и **32 именованных архетипа** — прямой ответ на «много сочетаний».
- Формализовано **дерево развилок** (стратегии легализации × общины × личность × концовки).
- **Система событий** доведена до схемы данных и планировщика, который сможет генерировать LLM пачками.
- Локации переописаны под **поиск готовых low-poly ассетов**.
- Добавлен слой **национального реализма** и явные **гард-рейлы тона**.

## Принципы, которые нельзя нарушать при реализации (резюме из v0.1)

1. **Парсер не выдумывает** — только маппит ввод на закрытый словарь глаголов/целей. Невозможное → `out_of_scope`.
2. **Рассказчик получает результат, а не право его выбирать.** Не раздаёт предметы, не называет цены, не обещает от лица NPC то, чего нет в стейте.
3. **Аналитик не управляет миром** — только начисляет дельты осей, которые код клампит.
4. **Оси не показываются числами.** Игрок видит последствия и редкие текстовые «отражения».
5. **Считается выбор, а не успех.** Провалившаяся кража — всё равно сдвиг LAW вниз.
6. Сид рандома логируется → исход воспроизводим.

## Глоссарий берлинской бюрократии (сквозной для всех документов)

| Термин | Что это в игре |
|---|---|
| **Anmeldung** | Регистрация по адресу. Ключ ко всему: без неё нет счёта, работы, SIM, страховки. Термина нет на недели вперёд. |
| **Bürgeramt** | Районная управа, где делают Anmeldung и базовые документы. |
| **Ausländerbehörde (LEA)** | Ведомство по делам иностранцев. Решает судьбу статуса. Ведёт **дело** на тебя — общая память с Bürgeramt. |
| **Aufenthaltstitel** | Вид на жительство (виза/разрешение). Бывает по работе, учёбе, убежищу, воссоединению. |
| **Blue Card / §18b** | ВНЖ для квалифицированных специалистов с контрактом и зарплатой выше порога. |
| **Aufenthaltsgestattung** | Временное разрешение на время рассмотрения убежища. |
| **Duldung** | «Терпимое пребывание»: депортация приостановлена, но статуса нет. Подвешенность. |
| **Fiktionsbescheinigung** | Справка, что твой статус «продлевается» пока ведомство думает. Спасает от нелегальности в просвете. |
| **Schwarzarbeit** | Работа по-чёрному, без договора и страховки. Стройка, мойка, курьерка, уборка. |
| **Scheinselbständigkeit** | Фиктивное «самозанятие» — способ эксплуатации (особенно восточных европейцев). |
| **Scheinehe** | Фиктивный брак ради статуса. Серый путь. |
| **Sperrkonto** | Заблокированный счёт (~11 000 €) — условие студенческой визы. |
| **WBS / Schufa** | Справка о праве на соц-жильё / кредитный рейтинг — барьеры на рынке жилья. |
| **Heim / Sammelunterkunft** | Общежитие для беженцев. |
| **Zoll (FKS)** | Таможня/финконтроль, ловит Schwarzarbeit (облавы на стройках). |
| **Jobcenter / Bürgergeld** | Соцслужба и пособие (доступ зависит от статуса; у §24 — есть). |
