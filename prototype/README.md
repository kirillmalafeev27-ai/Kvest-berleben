# BERLIN: ÜBERLEBEN — текстовый прототип

Играбельная реализация цикла **Parser → Rules → Analyst → Narrator** из дизайн-макета
(`../design`). Это вертикальный срез линии **«Соискатель»** (Акт I + семена Акта II): прилёт,
Виктор, Bürgeramt (N1), Лена, первая работа (N2), смены, недоплата Богдана (N3), контроль в
U-Bahn, выдох в парке, честная лазейка (N4).

Работает **офлайн** на детерминированных заглушках. При наличии ключа подключается Claude —
теми же тремя ролями, без переписывания движка.

## Запуск

```bash
cd prototype
python3 play.py                      # интерактив (офлайн или Claude, если есть ключ)
python3 play.py --stub --debug       # офлайн + показ интентов/осей/«ведёт к»
python3 play.py --script demo_act1.txt --stub   # автопрогон демо
python3 play.py --load manual        # загрузить сейв
```

Зависимости: **только `PyYAML`** для офлайн-режима (`pip install -r requirements.txt`).
Для режима Claude — `pip install anthropic` и `export ANTHROPIC_API_KEY=...`.

## Команды в игре

`/look` осмотреться · `/me` состояние · `/map` соседние локации · `/goto <id>` перейти ·
`/next` закончить день · `/save [слот]` · `/load [слот]` · `/debug` показать оси/интенты ·
`/help` · `/quit`. Любой другой ввод — **свободное действие словами**:
«осмотреться», «иду к Бюргерамту», «честно объясняю чиновнице ситуацию», «плачу 60», «бегу».

## Архитектура

```
play.py                 точка входа (argparse)
berlin/
  cli.py                текстовый UI, команды, интерактив/скрипт
  engine.py             ОРКЕСТРАТОР: цикл Parser→Rules→Analyst→Narrator, ход времени, навигация
  parser.py             Parser:  свободный текст → интент из ЗАКРЫТОГО словаря (stub | Claude)
  rules.py              Rules:   условия входа, выбор ветки, скилл-чек (сидируемый RNG), эффекты
  analyst.py            Analyst: дельты осей — антифарм, контекст, инерция, кламп (stub | Claude)
  narrator.py           Narrator: текст исхода в голосе NPC (stub | Claude), «отражения» характера
  director.py           Режиссёр давления: tension → relief/pressure из пула
  state.py              GameState (dataclass) + персист в SQLite (сейвы, журнал событий)
  content_loader.py     загрузка YAML-контента
  llm.py                абстракция LLM: stub | claude (по ANTHROPIC_API_KEY)
content/
  economy.yaml          числа баланса (см. ../design/10_ekonomika_balans.md)
  verbs.yaml            закрытый словарь глаголов + русские ключи для stub-парсера
  locations.yaml        реестр локаций (../design/06)
  npcs.yaml             голос-карточки NPC (../design/story/01)
  events/soiskatel.yaml события Акта I в схеме движка (../design/05)
demo_act1.txt           демо-прогон (по строке на ход)
```

**Данные отдельно от кода:** события/NPC/локации/экономика — это YAML. Движок не знает их
поимённо, только применяет схему. Новый контент льётся без правки кода (design/05 §5.7).

## Что демонстрирует прототип

- **Закрытый словарь интентов** — парсер маппит свободный русский ввод на глаголы (28 шт.), не выдумывая действий.
- **Авторитарный резолв** — условия входа событий, сопоставление ветки по интенту, скилл-чеки с **воспроизводимым сидом** (`seed:turn:event:branch`).
- **Тихий характер** — Analyst лепит оси (AGGRO/TRUTH/ALTRU/LAW/PRIDE) из поступков с антифармом, смягчением по контексту (голод), инерцией и клампом; числа игроку **не показываются** (только редкие «отражения»).
- **Память мира** — флаги, счётчики, репутация фракций, граф слухов, **общее дело чиновников** (отложенные выстрелы: соврал на N1 → всплывёт позже).
- **Узлы-стрелки** N1→N2→N3→N4 и их последствия; **режиссёр давления**; смена дня и таймер визы; **персист в SQLite**.

## Режим Claude (опционально)

При `ANTHROPIC_API_KEY` те же роли исполняет модель (системные промпты — в `parser.py`,
`narrator.py`):
- **Parser** — закрытый каталог глаголов/целей, строгий JSON, temperature 0.
- **Narrator** — факты сцены + выбранный движком исход + стиль-карточка NPC, temperature ~0.8, запрет выдумывать факты/цены/обещания.
- **Analyst** — дельты осей; код всё равно клампит.

Движок **детерминированно деградирует** к заглушкам, если вызов не удался.
